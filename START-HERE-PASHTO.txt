DARMAN DIGITAL LIBRARY — د چلولو او خپرولو لارښود

۱. ZIP خلاص کړئ او هغه فولډر په VS Code کې خلاص کړئ چې package.json پکې دی.
۲. Terminal کې npm install، npm run check او npm run dev وچلوئ.
۳. npm run build او npm run preview سره تولیدي نسخه وازمویئ.
۴. د موجودې GitHub/Vercel پروژې فایلونه په دې نسخه تازه کړئ، زاړه غیرضروري فایلونه حذف کړئ او د Google Verification فایل یا meta tag وساتئ.
۵. git add -A، git commit -m "Darman Digital Library SEO update" او git push origin main.
۶. که مستقیم Vercel CLI کاروئ، د هماغې موجودې پروژې دننه vercel --prod وچلوئ.
۷. اصلي لینک: https://ketabton.vercel.app/ — نوم بدل شوی، لینک هماغه دی.
۸. Search Console کې sitemap.xml ثبت کړئ او د اصلي پاڼې Request Indexing یوازې یو ځل وکړئ.

یادونه: د کتابونو اصلي سرچینې او د خپرونکو لینکونه نه دي بدل شوي. د Google د پایلو وخت او درجه تضمین نه لري. د جزئیاتو لپاره README.md وګورئ.
